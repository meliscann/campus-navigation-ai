# Campus Navigation AI

This project implements a multi-floor campus navigation system using:

- Classical Search Algorithms (BFS, UCS, A*)

- Grid-based multi-floor campus modeling
- Visualization of paths, utilities, and policies

## Features
- 6-floor campus map
- Elevators, stairs, escalators
- Semantic areas (classrooms, library, restaurants, terrace)


## How to Run

### Search
```bash
python main_search.py

```
